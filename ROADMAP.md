# Roadmap

## v0.4 — Release público de investigación

- [x] Pipeline reproducible y validación dura.
- [x] Comparaciones probabilísticas pareadas con incertidumbre.
- [x] Robustez de liquidez sin look-ahead.
- [x] Validación expanding rolling-origin.
- [x] CI, licencia, ficha pública y materiales para LinkedIn.

## v0.5 — Eficiencia experimental

- [x] Reanudar etapas completas mediante hashes de datos, configuración, código y salidas.
- [x] Migrar a un paquete instalable con CLI única.
- [x] Separar planificación sin efectos, chequeos rápidos y validación completa.
- [x] Ampliar CI a Ruff, Pyright, build y Python 3.11–3.12.
- [ ] Cachear folds individuales para recuperar ejecuciones rolling-origin interrumpidas.
- [ ] Perfilar BCD y reducir recomputaciones de gradientes.
- [ ] Ejecutar rolling-origin en paralelo con límites explícitos de memoria.

## v0.6 — Evidencia prospectiva

- [ ] Congelar hipótesis, configuración y código antes de observar nuevas fechas.
- [ ] Reservar un holdout futuro verdaderamente sellado.
- [ ] Añadir un proveedor institucional o una segunda fuente para reconciliación.
- [ ] Evaluar costos dependientes de liquidez, spread y capacidad.

## v1.0 — Solo si la evidencia lo justifica

- [ ] Política formal de promoción/rechazo de modelos.
- [ ] Monitoreo de drift, calidad y fallos del proveedor.
- [ ] Registro de modelos y experimentos inmutable.
- [ ] API o dashboard de investigación, sin presentar resultados como recomendación de inversión.
